# Chrome Extension Simple Template (Vite + TypeScript + pnpm)

This is a **minimalist, production-ready starter template** for building Google Chrome Extensions (Manifest V3) using `pnpm`, `Vite`, and `TypeScript`.

This template uses a simple "Hello World" Chrome extension as an example.
For more details, please refer to the [official tutorial](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world).

## Prerequisites

- **Node.js**: current LTS version
- **Package Manager**: pnpm

## Quick Start (How to use this template)

### 1. Initialize Project

Clone or copy this template, then install the dependencies:

```bash
pnpm install
```

### 2. Build the Extension

Run the build script to compile TypeScript and bundle assets. This will generate a production-ready `dist` folder:

```bash
pnpm build
```

### 3. Load into Google Chrome

1. Open Google Chrome and navigate to `chrome://extensions/`.
2. Enable **Developer mode** using the toggle switch in the top-right corner.
3. Click the **Load unpacked** button in the top-left corner.
4. Select the generated `dist` directory in your project root.

## Template Structure

Feel free to customize and expand this directory structure based on your project needs:

```text
├── coverage/                # Generated by `pnpm coverage` (Coverage reports)
├── dist/                    # Build output (Load this folder into Chrome)
├── hello.html               # Template for Popup UI HTML
├── oxfmt.config.ts          # Template for formatter configuration (Oxfmt)
├── oxlint.config.ts         # Template for linter configuration (Oxlint)
├── package.json
├── pnpm-lock.yaml
├── public/
│   ├── hello_extensions.png # Extension icon file
│   ├── manifest.json        # Extension configuration (Manifest V3)
│   └── README.md
├── src/                     # Extension source codes
│   └── popup.ts             # Template for Popup logic script
├── tests/                   # Unit/Integration tests
│   └── popup.test.ts        # Template for Popup logic test
├── tsconfig.app.json        # TypeScript configuration for extension application code
├── tsconfig.json            # Main TypeScript configuration (References sub-configs)
├── tsconfig.node.json       # TypeScript configuration for Vite config / Node environment
├── vite.config.ts           # Optimized Vite configuration for extensions
├── vitest.config.ts         # Template for Vitest configuration
└── vitest.setup.ts          # Template for test configuration and mocks
```

## Available Scripts

- `pnpm build`: Bundles, minifies, and optimizes into the `dist` directory.
- `pnpm dev`: Build in development mode.
- `pnpm watch`: Rebuilds in development mode when modules have changed on disk.
- `pnpm test`: Run all test suites.
- `pnpm coverage`: Run tests and generate coverage report in `coverage/`.
- `pnpm lint`: Checks the code for syntax errors and style violations.
- `pnpm fmt`: Automatically formats the code to match the project's style guide.
- `pnpm fmt:check`: Verifies if the files are formatted correctly without making changes (useful for CI).

## Customization Guide

This template is designed to be easily extensible:

- **Adding Service Workers**: Create a background script file under `src/` and register it in `public/manifest.json`.
- **UI Frameworks**: You can easily integrate UI libraries like React, Vue, or Tailwind CSS on top of this template using standard Vite plugins.
- **Permissions**: Add requested Chrome APIs (e.g., `storage`, `tabs`) inside `public/manifest.json`.
